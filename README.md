# Wydania StudioOS

Tu są tylko paczki StudioOS dla Windows do pobrania. Nie ma tu kodu źródłowego w Gicie ani żadnych danych.

Najnowsza wersja: zakładka **Releases** po prawej. Pobierz plik `StudioOS-<wersja>-windows.zip`, rozpakuj i kliknij dwukrotnie **Zainstaluj StudioOS**. Instalacja jest dla jednej osoby, bez uprawnień administratora; Python nie jest potrzebny. Szczegóły w pliku `Przeczytaj mnie.txt` w rozpakowanym folderze, a wprowadzenie w `Samouczek StudioOS.html`.

Zainstalowany StudioOS sam sprawdza, czy jest tu nowsze wydanie, i instaluje je dopiero po kliknięciu **Zaktualizuj** w Ustawienia → Studio. Każde wydanie jest podpisane; pliki `studioos-wydanie.json` i `.sig` są dla programu, nie trzeba ich pobierać.

Pakiet nie zawiera niczyich danych, kluczy ani kont: klucz Notion, skrzynki i silnik asystenta każda osoba dodaje sama, swoje, i zostają one tylko na jej komputerze.
