# Wydania StudioOS

Tu są tylko paczki StudioOS dla Windows do pobrania. Nie ma tu kodu źródłowego ani żadnych danych.

Najnowsza wersja: zakładka **Releases** po prawej. Pobierz plik `StudioOS-<wersja>-windows.zip`, rozpakuj i kliknij dwukrotnie **Uruchom StudioOS**. Szczegóły w pliku `Przeczytaj mnie.txt` w rozpakowanym folderze.

Pakiet nie zawiera niczyich danych, kluczy ani kont: klucz Notion, skrzynki i silnik asystenta każda osoba dodaje sama, swoje.
